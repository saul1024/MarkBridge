本机说明

这是跑在你这台电脑上的网页，不是云应用。书签文件、Chrome / Edge Profile 都留在运行 markbridge web 的机器上。

  • 只监听 127.0.0.1，局域网和公网访问不到。
  • COS 密钥来自当前目录的 .env 或环境变量，不会下发到浏览器。
  • 必须在有 Chrome / Edge 用户数据的那台电脑上启动。换一台机器就看不到这边的 Profile。
  • 写入浏览器会改本机 Bookmarks 文件。所有写操作都先预览，再点「执行」。
